# HZP Amazon 5-3｜图片视频策划

## 定位与边界

5-3 回答：“消费者应该按什么顺序看到什么、相信什么、少担心什么，以及每个画面如何保持真实？”它把 5-1 页面战略、5-2 文案和真实产品素材转成主图策略、副图序列、图片任务卡、A+ 视觉结构、视频信息脚本、素材清单和 AI 出图执行提示。

- 5-1 = 页面销售战略；5-2 = Listing 文案；5-3 = 图片/A+/视频视觉策划；5-4 = 页面整体审核优化。
- 不重新定义页面战略、重写完整 Listing、开发产品、做市场分析、批准所有 Claim、改变真实产品结构或制作图片/视频成片。
- 视觉首先服务于消费者理解、差异化、购买理由和信任；高级感只能在不牺牲真实性和清晰度的前提下使用。
- 一次运行连续完成已定义步骤，不要求用户逐阶段确认。

## 产品身份与必读输入

1. 使用本次确认的 Products Root、Product Root，读取同一 Product Root 的 `01_产品档案.md` 和 `03_产品页面思路.md`。确认 Product Code、产品中文名称、站点和页面人工思路；身份缺失或冲突时停止，输出 `[产品档案缺失]`、`[产品身份冲突]` 或 `[产品身份无法确认]`。禁止根据 ASIN、文件名或图片猜产品名称。
2. 在 `[Product Root]/06_SKILL分析报告/` 中定位当前产品最新有效 5-1 和 5-2 正式 HTML：按当前 Product Code + Skill 编号匹配，最大 V 优先，同 V 按文件名 `YYYYMMDD_HHMMSS` 最新。排除 `index.html`、Draft、Preview、Test、Temp、Demo、Debug、失败、未完成、废弃和无效文件；不得按目录顺序或文件系统时间选取。异常最新版仍需标记 `[建议复核上游最新版]`，不得静默回退。
3. 必须优先读取 5-1《5-3输入交接包》和 5-2《5-3文案协同包》，二者是核心输入。实际回查 4-2、4-1、3-3、3-2、3-1、2-2、2-1 时只核对结构真实性、材料、性能 Claim、消费者痛点或差异化，不重新完整执行上游 Skill。若 4-1/4-2/07 真实状态与 5-1/5-2 冲突，优先真实当前状态；影响页面战略时输出 `[上游页面战略冲突｜需返回5-1/5-2]`。
4. 主动扫描同一 Product Root 的 `07_产品资料/`，识别实拍图、样品照片、多角度图、包装/配件、尺寸图、工程图、结构图、安装图、使用素材、材质/工艺细节、工厂图、场景素材、Logo 和品牌素材。文件名只是线索，必须查看实际内容和版本；没有真实产品素材时不得幻想产品外观。

正式 HTML 必须生成《输入版本追溯》，记录实际读取的 5-1、5-2（`[核心输入]`）、按需回查报告（`[辅助回查]`）和 07 素材（非版本化资料）。

## 证据和真实性总则

继承 `[已确认事实]`、`[实测数据]`、`[测试结果]`、`[消费者证据]`、`[工程确认]`、`[供应商确认]`、`[文件记录]`、`[项目主张]`、`[分析推断]`、`[待验证]`、`[证据不足]`。5-2 Claim 状态必须原样继承：`【可直接表达】`、`【建议弱化表达】`、`【需补证据】`、`【禁止表达】`。不能通过图片、动画、构图或视频暗示绕过禁止/待验证 Claim；未确认数字、材料、承重、安全、认证、专利或性能不得上图。

如果 5-1、5-2 或 3-2 与 4-1、4-2、07 真实产品描述冲突，采用真实当前状态，不把旧结构画回来。对复杂结构逐项检查漏件、多件、错接、断裂、悬空、错误孔位、错误比例、错误安装和不可实现连接。场景必须符合放置位置、使用方式、力学方向、人体动作、家具关系和真实尺寸比例。

## 固定执行流程

读取身份 → 读取 03_产品页面思路 → 选取最新 5-1 → 读取《5-3输入交接包》 → 选取最新 5-2 → 读取《5-3文案协同包》 → 扫描 07 真实素材 → 按需回查上游 → 视觉核心战略 → 主图策略 → 图片序列规划 → 图片任务卡 → 产品视觉真实性约束 → 场景真实性要求 → 视觉 Claim—Evidence → A+视觉结构 → 视频信息脚本 → 素材缺口清单 → AI 出图 Prompt（如适用）→ 视觉策略分歧 → 反方检查 → 5-4 输入交接包 → 生成正式 HTML → 确认落盘 → 调用 0-2。

## 必须生成的策划内容

### 《视觉核心战略》

包含产品身份、目标消费者、核心场景、页面 P0/P1/P2、第一视觉目标、第一购买理由、核心视觉差异化、最需要证明的信息、最大顾虑、消费者第一感受、页面调性、最大视觉风险和最大素材缺口。视觉不以“高级”作为单独目标。

### 《主图策略》

明确主图第一任务、消费者第一眼应认出的产品、最显著价值、必须清楚的结构、套装完整性、产品占画面比例和视角方向、材质/结构细节、禁止内容与 Amazon 主图合规风险。主图只承担识别、第一印象、点击欲望和真实性，不塞入全部数字、场景和说明；若没有可核对的主图政策资料，标记 `[Amazon主图规则待核对]`，不得声称“完全符合最新政策”。

### 《图片序列规划》与《图片任务卡》

图片数量按产品实际情况决定，不机械固定 7 张。通常由主图承担识别，副图依次承担 P0/购买理由、差异化/结构证据、材料、安装/使用、场景、顾虑解除、尺寸/套装，但必须按证据动态调整。

每张图都必须只有一个明确主要任务，并回答“看完后多理解什么、多相信什么或少担心什么”。每张《图片任务卡》至少记录：图片编号、角色、页面 P0/P1/P2、消费者问题、唯一核心任务、卖点、核心视觉、推荐短文案、必须真实展示部位、素材来源、是否场景/人物/结构放大/尺寸/对比、Claim、Claim 状态、真实性要求、禁止修改内容、允许视觉优化内容、素材缺口和 AI 注意事项。禁止只写“做一张高级场景图”。

### 《产品视觉真实性约束》

明确三类：

- **绝对不可修改：**核心结构、零件数量、连接关系、孔位、安装逻辑、核心比例、材料外观特征、实际售卖内容、功能关系和关键尺寸逻辑。
- **允许视觉优化：**灯光、背景、阴影、摄影角度、景深、构图、合理透视、排版、环境、清洁度和色彩校正。
- **需要确认后才能修改：**尺寸、包装、脚垫/连接件、材料等级、表面处理、套装内容、性能数字和品牌/Logo。

如果使用 AI 生成或编辑，真实产品实拍/工程资料是结构和外观最高优先级；文字 Prompt 不能覆盖参考图。复杂结构必须检查错接、漏件、多件、断裂、悬空、镜像导致的方向错误。

### 《场景真实性要求》

检查产品放置位置、使用方式、安装位置、力学方向、人体动作、家具/设备关系、产品比例和环境是否与消费者场景匹配。不得为营销把产品装到错误位置、画出松垮受力、改变功能方向或制造不可能的使用结果。人物仅在服务目标消费者、场景、比例和购买情绪时使用。

### 《视觉Claim—Evidence表》

至少记录视觉 Claim、对应图片/视频、消费者价值、证据来源/类型、5-2 状态、是否允许正式视觉表达、推荐表达强度、风险和处理方式。`【可直接表达】`仍需确认画面不夸大；`【建议弱化表达】`必须同步弱化；`【需补证据】`不能作为正式强 Claim 上图；`【禁止表达】`不能通过视觉绕过。

### 《A+视觉结构》

按模块说明顺序、任务、核心信息、对应 P0/P1/P2、视觉类型、文字角色、所需素材、Claim 证据、主要顾虑和是否必须。A+ 可承担完整解释、品牌强化、结构证明、场景扩展、对比和 FAQ，但不能机械复制副图，也不能改变 5-2 A+ 文字基础中的核心 Claim。

### 《视频信息脚本》

这是信息结构，不是影视成片脚本。按产品动态决定时长；可参考 0–3 秒产品识别/购买理由、3–8 秒整体/差异化、8–15 秒结构/材料/证据、15–23 秒安装/使用、23–28 秒场景、28–30 秒购买理由收束，但不得机械固定。每段记录时间、核心任务、画面、产品动作、镜头重点、字幕/短文案、对应 Claim、证据状态、所需素材、禁止表达和转场逻辑。不得用剪辑、动画或不存在的测试制造性能；未真实完成的测试不能伪装成实拍。

### 《素材缺口清单》

按“制作前必须补、可后补、AI 可辅助、必须真实拍摄/实测”分类，逐项说明缺少素材会影响哪张图/哪段视频/哪个 Claim。某一视频素材缺失不自动阻止其他图片规划；但连真实产品外观、结构或配件数量都无法确认时，使用关键素材不足状态，不得继续幻想。

### AI 出图 Prompt

仅在适用时为已确定的图片任务生成少量 Prompt。每个 Prompt 必须写明真实产品参考图优先、禁止改变结构/比例/零件/材质特征、真实场景比例、需保留的可见部件、允许的灯光背景优化、禁止的 Claim 暗示和输出用途。Prompt 服务于任务卡，不能取代视觉战略；不要一次输出大量风格变体。

### 《视觉策略分歧》

若人工视觉想法与 5-1 战略、5-2 Claim、消费者证据或真实产品冲突，记录人工想法、证据/策略观点、冲突、风险和建议处理，不得偷偷忽略或让人工偏好覆盖事实。

### 《反方检查》

至少检查：主图是否传达最重要价值；是否为高级感牺牲真实性；一张图是否塞太多卖点；次要视觉是否抢 P0；AI 是否新增/删除/错接结构；场景和安装是否错误；是否以视觉暗示绕过 Claim；是否有未确认数字或材料；是否把消费者感知写成工程事实；对比图是否伪造竞品；视频是否剪辑制造不存在性能；需要实拍的内容是否错误地全交给 AI；人工视觉是否与页面战略冲突；只看主图+前两张副图是否理解核心购买理由；为什么采用当前方案。

## 最终状态

只允许：

- `【视觉方案已形成｜可进入制作】`
- `【视觉方案基本形成｜部分素材待补】`
- `【关键真实素材不足｜暂无法形成可靠视觉方案】`
- `【关键Claim未确认｜部分视觉内容暂不可制作】`
- `【上游页面战略冲突｜需返回5-1/5-2】`

素材局部缺失时继续完成可用部分并标记 `[素材待补]`；只有真实产品外观、结构或配件无法确认时，才使用关键真实素材不足。
