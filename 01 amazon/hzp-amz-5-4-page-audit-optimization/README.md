# HZP Amazon 5-4｜页面审核优化

## 30 秒运行

```text
使用 5-4 Skill
产品：P001
Products Root：E:\【产品总目录】
```

5-4 把 5-1 页面策略、5-2 Listing 文案、5-3 图片视频策划和可用的真实页面成品放在同一条购买路径中审核，找出真正影响理解、信任、点击、转化或真实性的问题。

## 审核类型

- 有真实页面成品时：`【真实页面成品审核】`
- 只有计划稿时：`【策划阶段页面审核】`

## 输出

正式报告写入：

`[Product Root]/06_SKILL分析报告/5-4_[产品编号]_页面审核优化_Vx_YYYYMMDD_HHMMSS.html`

报告包含战略一致性、前 5 秒、文案—视觉一致性、购买路径、Claim、SEO/可读性、真实性、P0/P1/P2 修改清单和条件满足时的 6-1 交接包。正式报告成功后自动调用 0-2 更新索引；5-4 不自行维护 `index.html`。

5-4 负责审核和分流，不替代 5-1/5-2/5-3 完成全部制作，也不直接制定广告方案。
