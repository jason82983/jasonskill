# HZP Amazon 6-0-2｜精准泛词提取

Machine Name：`hzp-amz-6-0-2-precision-broad-extraction`

6-0-2 只读取 6-0-1 的 `6-0-1_[Product_Code]_AI精准词.csv`，不重新连接 SQL 或判断精准词。每行输入固定六列：`自动编号`、`关键词`、`搜索量`、`中文名称`、`精准理由`、`精准度`；`自动编号`仅用于上游追溯，6-0-2忽略它。

运行：

```text
6-0-2，Product_Code
```

处理顺序：规范化 → 按 Keyword 去重 → 按共同购买意图合并 → 提取至少两个英文单词的最小有效精准泛词 → 合计同意思词的已知搜索量 → 降序输出。自动编号只作追溯，不参与聚类或 SUM。词序、介词和单复数变化在意图一致时可合并；明确不同的节日或场景不得强行合并。缺失搜索量不估算、不当作 0；同 Keyword 多 ID 且搜索量相同只计一次；搜索量冲突且无法可靠解决时输出 `[DUPLICATE_KEYWORD_VOLUME_CONFLICT]`，不得相加。

唯一输出：

```text
06_SKILL分析报告/6-0-2_精准泛词提取/6-0-2_[Product_Code]_精准泛词.csv
```

最终 CSV 严格只有三列：`词`、`中文`、`同意思词的合并总量`。6-0-2 不生成关键词族、排名分析、广告策略或广告写操作。
