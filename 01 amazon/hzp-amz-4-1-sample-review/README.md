# HZP Amazon 4-1｜打样评审

## 30 秒运行

```text
使用 4-1 Skill
产品：P001
Products Root：E:\【产品总目录】
```

4-1 会读取当前产品最新有效的 3-3 方案评审和《4-1输入交接包》，再结合真实样品证据判断样品是否实现了批准的产品方案。

## 什么时候使用

只有 3-3 已明确允许进入打样，并且当前 Product Root 中存在可识别的真实样品资料时使用。4-1 不重新做市场分析、机会定义、完整产品设计或量产 QC。

## 必须有的样品证据

样品编号/轮次，以及照片、视频、实测、测试、人工体验、工厂/供应商确认、BOM、包装或问题记录中的可靠证据。没有能代表真实样品状态的证据时，输出“【证据不足｜暂无法完成样品评审】”，不得只凭纸面方案放行。

## 输出

正式报告写入：

```text
[Product Root]/06_SKILL分析报告/
4-1_[产品编号]_打样评审_Vx_YYYYMMDD_HHMMSS.html
```

报告包含方案—样品一致性、核心功能/工程验证、消费者体验、初步质量、问题归因、反方检查和下一步决策。只有通过或有条件通过且条件满足时，才生成《4-2输入交接包》。正式 HTML 成功后自动调用 0-2；4-1 自己不生成 `index.html`。
