# HZP Amazon 3-2｜差异化产品开发

## 30 秒运行

```text
使用 3-2 Skill
产品：P001
Products Root：E:\【产品总目录】
```

3-2 会读取当前产品档案、最新 3-1《3-2输入交接包》，按需回查 2-1/2-2/2-3 和 `07_产品资料`，把已确认的产品机会转化为可评审、可打样、可验证的差异化产品方案 V1。

## 适用场景

当 3-1 已明确 P0/P1 产品机会，需要进入具体产品设计、候选方案比较、打样准备和验证计划时使用。

3-2 负责 HOW；不重新做市场分析、不重定义机会、不批准最终量产。

## 输出

报告保存到：

```text
[Product Root]/06_SKILL分析报告/
3-2_[产品编号]_差异化产品开发_Vx_YYYYMMDD_HHMMSS.html
```

报告包含产品设计目标、候选差异化方案、机会—设计追溯矩阵、推荐方案 V1、Amazon 可表达差异点、风险与验证计划和《3-3输入交接包》。正式报告成功后自动调用 0-2 更新索引；3-2 自己不生成 `index.html`。


上游报告规则：如本次读取其他 Skill 正式报告，只在当前产品的 06_SKILL分析报告/ 中按产品编号、Skill 编号、最大 V 版本和同版本最大文件名时间戳选择最新有效正式版本；实际使用的文件会写入 HTML《输入版本追溯》。
