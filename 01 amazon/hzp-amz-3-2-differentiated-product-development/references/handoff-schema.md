# 3-3 输入交接包

HTML 末尾的《3-3输入交接包》至少包含：

1. 推荐差异化产品方案 V1 与推荐理由
2. 对应 P0/P1 机会、目标消费者、核心场景和核心问题
3. 产品结构、材料、关键规格、功能、配件、BOM V1、工艺、CMF、包装
4. 消费者价值、核心购买理由和 Amazon 可表达差异点
5. 已确认事项、项目约束、方案建议
6. `[工程待验证]`、`[成本待验证]`、`[供应链待验证]`、`[IP风险待验证]`、`[合规风险待验证]`、`[消费者价值待验证]`
7. 主方案最大弱点、备选方案、必须验证事项和主方案推翻条件

每个字段保留证据来源和状态；未确认内容不得写成定版事实。
