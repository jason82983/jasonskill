# HZP Amazon 2-3｜人工判断与AI同步

## 30 秒运行

```text
使用 2-3 Skill
产品：P001
Products Root：E:\【产品总目录】
```

2-3 会读取当前产品的 `01_产品档案.md`、`02_产品开发思路.md` 和最新 2-1/2-2 正式报告，整理人工判断与 AI 证据的关系，并生成一份中文同步报告。

## 什么时候使用

当你已经有产品开发思路，想确认“人工怎么看、AI/数据怎么看、哪里一致或冲突、哪些事项交给 3-1 验证”时使用。它不是重新做产品分析，也不是市场 GO/NO-GO 决策。

## 运行前准备

- 当前产品目录中存在 `01_产品档案.md`。
- 主要人工输入写在 `02_产品开发思路.md`。
- 需要对照的 2-1、2-2 报告放在 `06_SKILL分析报告/`。

如果缺少人工输入，2-3 会停止正式同步，不会替你编造人工观点。2-1 或 2-2 单独缺失会在报告中标注；两者都缺失时无法形成正式人机同步。

## 输出

报告保存到：

```text
[Product Root]/06_SKILL分析报告/
2-3_[产品编号]_人工判断与AI同步_Vx_YYYYMMDD_HHMMSS.html
```

报告包含人机一致项、同步矩阵、重大冲突、人工补充信息、人工假设池和《3-1输入交接包》。正式报告成功后会自动调用 0-2 更新当前产品的报告索引；2-3 自己不生成 `index.html`。
