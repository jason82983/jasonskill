# HZP Amazon 0-5｜上级决策与经营问询

0-5 每周从 Amazon 各阶段的最新有效报告和近期变化中，筛选真正需要老板决定的方向、预算、资源、风险或继续/停止事项，并生成简短决策周报。

## 怎么用
```text
使用 0-5 Skill
Products Root：E:\【产品总目录】
```
也可使用 `0-5，B2`、`0-5，待决策` 或 `0-5，已决策`。

## 输出
- P0/P1/重要 P2 决策问题与 A/B/C/D 选项
- AI 推荐、事实证据、截止时间和不决策后果
- 跨周 Decision Register、老板原始回答、执行路由和重新打开记录
- 无重大事项时的明确空结果

资料保存在 `[Products Root]/00_公共资料/02_公司标准/上级决策【0-5】/`，不进入产品 `06_SKILL分析报告` 或 0-2。

0-3 提供时间风险候选，0-4 提供规则与合规依据；0-5 只整理需要上级决断的问题，不执行广告、产品、页面或库存操作。

## Decision Inbox

日常经营表达可以先用 `0-5，记一下：原话` 进入候选收件箱。候选先观察，不会自动变成老板问题；每周结合新证据后再决定观察、合并、关闭或升级。原始用户原话与 AI 推测分开保存。
