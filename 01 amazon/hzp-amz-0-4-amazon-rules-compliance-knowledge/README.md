# HZP Amazon 0-4｜Amazon规则、合规与官方知识

0-4 是 Amazon 规则查询器、合规助手和公司公共知识库入口。

## 怎么用

```text
0-4，FBA外箱要求
0-4，Amazon US Title规则
0-4，某某产品需要什么认证？
0-4，找以前查过的广告规则
```

先告诉 Codex 当前 `Products Root`，例如 `E:\【产品总目录】`。知识库固定位置为：

`[Products Root]/00_公共资料/01_Amazon平台资料/日常知识【0-4】/`

## 它会做什么

- 先查已有公司知识，再按时效决定是否核验最新版官方资料；
- 分开 Amazon 平台要求、美国法规、FBA/物流要求和 HZP 公司经验；
- 给出证据状态、风险等级、官方来源链接和仍需确认的事项；
- 对复杂、易变或长期复用主题生成专项 HTML，并更新 0-4 知识首页；
- 产品专项合规查询只读产品资料，不修改产品档案。

简单的一次性问题直接回答；复杂问题才生成专项报告。0-4 知识报告与产品正式报告分开，不进入 0-2。
