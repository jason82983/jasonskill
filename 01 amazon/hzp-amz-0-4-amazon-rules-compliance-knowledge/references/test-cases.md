# 0-4 验证用例

- A：已有低风险且刚核验的知识，直接引用并给出状态。
- B：HIGH change risk 且核验较旧，重新查询官方资料。
- C：规则变化时生成新版，用 superseded_by 关联旧条目。
- D：简单一次性操作只回答，不强制 HTML。
- E：复杂认证问题生成专项 HTML，分开 Amazon 与法规要求。
- F/G：来源冲突时并列呈现，官方优先但不静默覆盖。
- H：产品事实不足时标记 `[产品事实不足]`，不猜认证。
- I/J：从 index 元数据列出分类或过期知识。
- K/L：同主题无变化不重复生成；有变化保留历史并关联新版。
- M/N/O：报告相对链接返回首页；index 不返回自身；0-4知识不进入0-2。
