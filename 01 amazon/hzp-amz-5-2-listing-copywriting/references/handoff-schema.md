# 5-2 交接包字段

## 5-3 文案协同包

- 5-2 最终状态和 5-1 来源版本
- 推荐 Product Title（字符数/75）与 Item Highlights（字符数/125），以及页面 P0/P1/P2、核心购买理由和核心差异化
- Core Selling Points（P0/P1/P2/P3）及其 Feature、Consumer Benefit、Reason to Buy、证据和推荐载体
- 产品属性、Material、Dimensions、Included Components、Target Audience、Occasion、Recommended Use（按实际存在的字段交接）
- 适合上图的短卖点、可视觉化 Claim、可展示数字/材料/结构
- 需要视觉证明的信息、安装/使用重点和消费者顾虑
- 适合视频表达的信息
- Keyword Allocation（Title / Item Highlights / Bullet / Backend / Attributes / A+ / Image Copy）
- Allowed Claims、Pending Claims、Forbidden Claims、禁止视觉夸张和证据状态

## 5-4 输入交接包

- 5-2 最终状态
- 推荐 Product Title（字符数/75）、Item Highlights（字符数/125）、正式 Bullet Points、Product Description、A+ 文字建议
- Backend Search Terms、Keyword Allocation 和去重/风险检查
- Listing Attributes（Value、Source、Evidence Status、Missing/Conflict）
- Core Selling Points（P0/P1/P2/P3）
- Amazon Listing Creation Data Package 完整度与 Listing 创建准备度
- 核心关键词地图
- 页面 P0/P1/P2、核心 Claim 及证据状态
- 待验证 Claim、禁止表达
- SEO 与可读性检查结果
- 产品属性冲突、缺失数据、Title/Item Highlights 重复或超长问题
- 需要 5-4 重点审核的问题

两个包必须来自同一份页面策略和同一套证据状态。交接包不替代正式 Listing 审核，也不改变 5-1 战略。
