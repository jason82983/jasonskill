==================================================
一、Skill定位
==================================================

1-2负责：

基于1-1输出的候选商机，

快速检查：

- 需求是否值得继续验证
- 是否存在明显硬风险
- 市场是否允许新品进入
- 是否存在真实差异化空间
- 消费者是否可能感知差异
- 商业空间是否值得继续研究
- 物流/退货风险是否合理
- 供应链是否可实现
- 团队是否匹配
- IP / 合规是否存在明显高风险
- 失败成本是否可接受


目标不是：

最终判断产品是否值得做。


目标是：

决定：

“这个候选值不值得占用后续2阶段更深、更贵的分析资源？”


==================================================
二、Skill边界
==================================================

1-1 = 商机发现

1-2 = 选品初筛

2-1 = 产品分析

2-2 = 细分市场分析


固定链路：

1-1 商机发现
↓
候选商机池
↓
1-2 选品初筛
↓
进入深度分析的候选
↓
2-1 产品分析
↓
2-2 细分市场分析


1-1问：

哪里可能有机会？


1-2问：

这些候选里面，
哪些值得继续花时间？


2-1问：

这个具体产品本身到底怎么样？


2-2问：

它所在细分市场到底值不值得进入？


==================================================
三、第一原则
==================================================

1-2不是：

打分选品。


1-2的本质是：

Research Capital Allocation。


即：

把研究时间当成资金配置。


核心逻辑：

候选商机
↓
快速验证关键条件
↓
发现明显硬伤
→ 提前停止

没有明显硬伤
+
机会逻辑仍成立
+
值得继续验证
→ 进入2阶段

==================================================
十一、《项目硬约束》
==================================================

必须优先读取和识别：

当前项目真实约束。


可能包括：

- Marketplace
- 产品方向
- 目标售价
- 资金
- MOQ
- 体积/重量
- 利润要求
- 合规边界
- 时间要求
- 团队能力
- 供应链能力


必须区分：

[项目硬约束]

[项目偏好]

[人工判断]


项目偏好不能当市场事实。


==================================================
十二、Early Stop优先
==================================================

1-2运行后：

先检查是否存在明显提前终止条件。


如果已经出现：

有充分证据支持的强硬风险，

无需机械完成所有深度分析。


==================================================
十三、《Early Stop｜提前终止》
==================================================

允许提前终止的典型情况：

- 明显无需求
- 明显无法商业化
- 明显品牌结构性封锁
- 明显高IP风险
- 明显高合规风险且团队无能力处理
- 明显违反项目硬约束
- 明显供应链不可执行
- 明显物流经济性极差
- 明显生命周期已错过
- 明显失败成本过高


==================================================
十四、Early Stop必须有证据
==================================================

禁止：

AI感觉竞争大
→ Early Stop


AI觉得风险高
→ Early Stop


必须：

事实
+
证据
+
逻辑


如果证据不够：

【证据不足｜补数据后再筛】


而不是：

【初筛淘汰】


==================================================
十五、《硬风险检查》
==================================================

必须生成：

《硬风险检查》


至少检查：

- 需求硬风险
- IP硬风险
- 合规硬风险
- 品牌垄断
- 项目硬约束
- 供应链
- 物流经济性
- 生命周期
- 失败成本


状态只允许：

【无明显硬风险】

【存在可验证风险】

【存在高风险】

【证据不足】


==================================================
十六、需求初筛
==================================================

必须生成：

《需求初筛》


核心问题：

这个候选是否存在：

值得进入深度分析的真实需求？


可参考：

- Search Volume
- Search Trend
- Niche需求
- Click数据
- 新品表现
- Review数量/活跃度
- 市场活跃程度
- 用户行为信号


但：

1-2不是完整市场规模研究。


==================================================
十七、低竞争 ≠ 好机会
==================================================

如果：

竞争少

但：

需求同样很小，

不得称为：

蓝海。


必须区分：

【低竞争+真实需求】

vs

【低竞争+低需求】


==================================================
十八、高销量 ≠ 值得继续
==================================================

如果：

市场很大，

但：

品牌壁垒极强

价格恶性竞争

无差异化空间

失败成本巨大


仍然可能：

不值得进入2阶段。


==================================================
十九、《竞争与新品进入初筛》
==================================================

必须生成：

《竞争与新品进入初筛》


重点不是只看：

卖家数量。


应关注：

- 点击集中度
- 品牌集中度
- 产品同质化
- Review壁垒
- 新品进入能力
- 新品是否成功
- 价格竞争
- 广告密度
- 头部稳定性


==================================================
二十、新品进入能力
==================================================

必须重点判断：

过去一段时间：

是否有真正的新产品成功进入。


如果：

老链接强

但：

新品持续能进入，

说明市场可能仍开放。


如果：

长期没有新品成功，

是重要风险信号。


==================================================
二十一、新品失败不直接代表市场封闭
==================================================

需要区分：

新品本身差

vs

市场结构不允许新品进入。


证据不足时：

不得过度判断。


==================================================
二十二、品牌垄断
==================================================

必须检查：

消费者购买是否明显依赖：

品牌认知。


如头部高度集中，

必须进一步判断：

集中原因。


禁止：

Top 5集中高
→ 自动判品牌垄断。


==================================================
二十三、《差异化与可开发性》
==================================================

必须生成：

《差异化与可开发性》


检查：

是否存在值得在2/3阶段继续验证的：

- 材料升级
- 结构升级
- 功能优化
- 尺寸优化
- 安装优化
- 使用体验
- 配件
- 包装
- 场景适配
- 外观/CMF


==================================================
二十四、差异化逻辑
==================================================

有效差异化应尽量满足：

真实问题
+
产品可解决
+
消费者可感知
+
页面可表达
+
有购买意义


==================================================
二十五、禁止伪差异化
==================================================

不能因为：

多一个颜色

多一个配件

多一个不相关功能

包装更复杂

就自动认为：

差异化成立。


==================================================
二十六、《消费者可感知性》
==================================================

必须生成：

《消费者可感知性》


核心问题：

产品升级后，

消费者：

能不能看懂？

能不能感觉到？

买之前能不能理解？

用之后能不能感受到？


==================================================
二十七、页面可表达性
==================================================

必须初步判断：

差异化是否：

能够在Amazon页面中清楚表达。


例如：

主图

副图

视频

标题/文案


如果需要：

大量复杂教育

消费者才理解，

应标记：

[页面表达成本较高]


==================================================
二十八、工程升级 ≠ 消费者价值
==================================================

例如：

结构更厚

材料更强


如果消费者：

不在意

看不懂

没有相关问题


则：

不能自动成为：

核心差异化。


==================================================
二十九、《商业空间初筛》
==================================================

必须生成：

《商业空间初筛》


可以检查：

- 售价
- 价格带
- 大致成本
- 产品体积
- 产品重量
- 包装
- FBA结构
- 广告压力
- 退货风险
- 市场容量
- 潜在销量空间


==================================================
三十、没有真实成本不得伪精确
==================================================

如果没有：

采购成本
物流
FBA
广告
退货
促销


不得：

输出正式净利润。


可以使用：

【商业空间看起来合理】

【商业空间偏紧】

【商业空间明显危险】

【成本数据不足】


==================================================
三十一、利润目标
==================================================

如项目已有：

利润目标

日利润目标

毛利要求


1-2应作为：

项目商业约束参考。


但：

不得在证据不足时声明：

“该产品一定能达到目标”。


只判断：

是否存在：

支持该目标的商业可能性。


==================================================
三十二、《物流与退货风险》
==================================================

必须生成：

《物流与退货风险》


检查：

- 尺寸
- 重量
- 包装体积
- 易碎
- 超大/超长
- 空抛
- 安装
- 兼容性
- 尺码
- 舒适性
- 色差
- 使用复杂度
- 运输损坏
- 退货结构


==================================================
三十三、大件不能自动淘汰
==================================================

必须判断：

体积重量

相对于：

售价

毛利

竞争

差异化

是否合理。


禁止：

“大件”
→
直接淘汰。


==================================================
三十四、退货风险
==================================================

必须区分：

偶发退货

vs

结构性高退货风险。


例如：

尺码

舒适

兼容性

复杂安装


可能构成结构性风险。


==================================================
三十五、售后复杂度
==================================================

必须初步判断：

是否需要：

- 安装指导
- 补配件
- 技术支持
- 高频客服
- 换件
- 排障


隐藏售后成本：

必须进入风险判断。


==================================================
三十六、《供应链可行性》
==================================================

必须生成：

《供应链可行性》


检查：

- 工厂可获得性
- 工艺成熟度
- MOQ
- 模具
- 打样难度
- 原材料
- 质量控制
- 生产周期
- 成本波动
- 供应商稳定性


==================================================
三十七、供应链难度要结合团队能力
==================================================

区分：

【供应链难且我们不擅长】

【供应链难但我们有优势】


第二种：

可能反而是壁垒。


==================================================
三十八、供应商说能做 ≠ 已验证可量产
==================================================

供应商口头确认：

只能是：

[供应商初步确认]


不能直接写：

量产可行。


==================================================
三十九、《团队匹配》
==================================================

必须生成：

《团队匹配》


检查：

- 产品开发能力
- Amazon运营能力
- 广告承受能力
- 品牌要求
- 内容要求
- 站外要求
- 合规能力
- 售后能力
- 退货管理
- SKU管理
- 资金能力
- 执行周期


==================================================
四十、Market Opportunity ≠ Our Opportunity
==================================================

如果市场不错，

但严重依赖：

团队当前不具备的核心能力，

必须标记：

[当前团队匹配度偏低]


但：

不自动等于永久淘汰。


==================================================
四十一、《IP / 合规早期风险》
==================================================

必须生成：

《IP / 合规早期风险》


IP可检查：

- 明显仿款
- 强设计特征
- Patent提示
- 品牌独占
- 商标使用
- 产品结构风险


合规可检查：

- 儿童
- 婴儿
- 医疗
- 食品接触
- 电池
- 电气
- 化学品
- PPE
- 安全类
- 特殊认证


==================================================
四十二、1-2不做正式FTO
==================================================

无正式专利检索：

[IP风险待验证]


无正式法规依据：

[合规风险待验证]


禁止：

“未发现”
=
“无风险”。


==================================================
四十三、《生命周期与机会窗口》
==================================================

必须生成：

《生命周期与机会窗口》


可能状态：

【增长期】

【成熟期】

【衰退期】

【季节周期】

【短期趋势】

【无法判断】


==================================================
四十四、机会窗口 vs 执行周期
==================================================

必须比较：

机会可能持续时间

vs

分析
+
开发
+
打样
+
量产
+
运输
+
上线


如果：

执行完成时机会可能已经消失，

必须：

降低优先级。


==================================================
四十五、趋势品
==================================================

趋势品必须特别检查：

开发周期

供应链周期

库存风险。


禁止：

看到趋势增长就无条件进入。


==================================================
四十六、季节品
==================================================

季节性不自动淘汰。


必须判断：

- 旺季窗口
- 错过窗口风险
- 淡季库存
- 补货难度
- 现金占用


==================================================
四十七、《失败成本》
==================================================

必须生成：

《失败成本》


至少检查：

- 模具
- MOQ
- 首单库存
- 广告测试成本
- 认证成本
- 仓储
- 清货
- 售后
- 潜在诉讼/IP风险
- 时间成本


==================================================
四十八、证据要求与投入匹配
==================================================

必须遵守：

投入越大
↓
需要越强证据

投入越小
↓
可以接受更高不确定性


==================================================
四十九、低失败成本机会
==================================================

如果：

MOQ低

无模具

上线快

清货容易

合规简单

试错成本低


可以允许：

较低证据强度下

进入：

小规模进一步验证。


==================================================
五十、高失败成本机会
==================================================

如果：

模具昂贵

首单很大

认证复杂

库存高

开发周期长

清货困难


则：

进入2阶段前

应要求：

更高证据质量。


==================================================
五十一、《反向证据》
==================================================
