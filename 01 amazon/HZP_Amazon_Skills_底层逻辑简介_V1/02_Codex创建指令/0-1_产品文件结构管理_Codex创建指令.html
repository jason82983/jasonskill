本页用于回查“当初要求 Codex 如何实现”。除明确标注的原始转换页外，内容按当前已锁定设计规范重建为完整创建指令参考版。

创建目标

请在当前 HZP Amazon Skills 仓库中新建：

hzp-amz-0-1-product-file-structure

中文名称：

HZP Amazon 0-1｜产品文件结构管理

Skill定位

只负责建立、检查、整理、迁移产品文件结构；不产生商业结论。

0-1 是文件结构层。它不做选品、分析、开发、页面、广告或库存判断；只保证后续 Skill 有稳定、可追踪的资料位置。

核心输入

  • 产品编号
  • 中文产品名
  • Products Root / Product Root
  • CREATE / CHECK / ORGANIZE / MIGRATE 模式
  • 现有文件与目录

固定执行原则

  • 根目录格式：[产品编号] [中文产品名]
  • 原始数据与分析报告严格分开
  • 05_分析源数据只放输入，06_SKILL分析报告只放正式输出
  • 不修改原始数据内容
  • 不猜商业事实
  • 公共资料与产品私有资料分层

固定执行流程

确认对象身份
↓
读取必要输入
↓
检查输入有效性/数据语义
↓
执行核心判断
↓
主动寻找反向证据
↓
形成输出与状态
↓
生成交接包/路由
↓
生成正式HTML或明确失败原因

必须生成的核心输出

  • 规范化产品目录
  • 缺失/异常目录检查结果
  • 整理或迁移计划
  • 明确不确定项

状态约束

只使用本Skill定义的业务状态；不得自行创造含义相近但不可追踪的新状态。

  • 【结构正常】
  • 【存在结构问题】
  • 【需要整理】
  • 【需要迁移】
  • 【身份信息冲突｜停止】

证据与数据真实性

  • 只读取当前对象/当前Product Root的数据，不跨产品拼接。
  • 凡读取版本化正式分析报告，必须选择当前产品最新有效正式版本；最大V优先，同V异常重复时文件名时间戳最新优先。
  • 禁止依赖filesystem顺序、modified time、created time、first-found文件来判断最新版。
  • 最新版如果有效性无法确认，返回【上游报告有效性无法确认】，不得静默回退旧版。
  • 如果为了历史比较读取旧报告，必须标记【历史版本对照】，且当前正式输入仍是最新版有效报告。
  • 所有事实、推断、待验证必须区分；不得编造销量、利润、CPC、ACoS、Review、专利、合规、供应商、成本或测试结果。
  • 正式HTML中如实际读取了上游版本化报告，生成《输入版本追溯》，只记录真正读过的报告。

HTML与版本规则

  • 图表只使用真实数据；数据不足时写【数据不足，未生成该图表】；禁止虚假评分图、伪趋势线和无意义3D图。
  • 正式输出成功后，如处于正式Product Root并适用，则调用0-2更新唯一index.html；0-2失败不得删除已成功生成的正式报告。
  • 不要修改原始数据、历史正式HTML或其他Skill；不要git commit，不要git push。
正式文件名建议：
0-1_[产品编号]_产品文件结构管理_V[版本]_[YYYYMMDD]_[HHMMSS].html

绝对禁止

  • 把整理文件当成分析产品
  • 修改原始数据内容
  • 把报告放进05
  • 把原始CSV放进06
  • 身份冲突时继续执行
  • 越权替代相邻Skill
  • 为了让报告完整而补造不存在的数据
  • 因为旧版本结论更喜欢而改读旧版

轻量模拟测试

  • 正常数据：应形成符合本Skill边界的正式输出。
  • 关键数据缺失：应保留不确定性，不伪造结论。
  • 上游最新版与旧版冲突：必须使用最新版有效报告，并可提示建议复核上游。
  • 跨产品同名文件：不得读取。
  • 输入存在明显反向证据：必须进入结论，不能只保留支持证据。
  • 证据不足时：不得使用比证据更强的状态。
  • 不得修改真实产品历史HTML、原始数据或其他Skill。
  • 完成后不得git commit/git push。

完成后只汇报

  • 新建了哪些文件
  • 机器名是否为 hzp-amz-0-1-product-file-structure
  • 中文名是否为 HZP Amazon 0-1｜产品文件结构管理
  • 是否严格遵守本Skill边界
  • 是否使用真实数据与证据标签
  • 是否正确执行最新版有效报告规则
  • 是否生成规定输出与交接内容
  • 是否没有修改其他Skill/历史报告/原始数据
  • 是否没有运行未授权真实产品
  • 是否没有git commit/git push
