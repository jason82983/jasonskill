# HZP Amazon 1-1｜商机发现

## 30 秒运行

```text
使用 1-1 Skill
扫描范围：某某细分市场
Products Root：E:\【产品总目录】（如已有）
```

它会从真实 Amazon 搜索、评论、竞品、价格、趋势及供应链/团队信号中发现“需求—产品”候选商机，形成候选池并交给 1-2 初筛。它只发现和排序研究优先级，不替代完整产品分析，也不输出最终 GO/NO-GO。

有 Product Root 时，Skill 自动读取 `01_产品档案.md` 和 `05_分析源数据/`，生成到 `06_SKILL分析报告/1-1_[产品编号]_商机发现_V版本_日期_时间.html`，成功后调用 0-2 更新索引。纯市场扫描可只给扫描目录；此时不虚构产品编号，也不调用 0-2。

缺少普通数据会在报告中标记待验证并继续；只有市场对象、身份或关键证据无法确认时才会停止要求补充。候选数量不固定，允许没有候选。
