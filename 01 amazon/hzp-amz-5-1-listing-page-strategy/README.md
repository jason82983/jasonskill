# HZP Amazon 5-1｜页面策略

## 30 秒运行

使用 5-1 Skill
产品：P001
Products Root：E:\【产品总目录】

5-1 把已确认的产品价值、消费者问题、差异化和证据整理成页面销售战略，明确页面先讲什么、如何证明、放到哪个 Amazon 页面载体，并交给 5-2 文案与 5-3 图片/视频策划。

## 使用前

准备当前产品的 01_产品档案.md、03_产品页面思路.md，以及 06_SKILL分析报告 中的上游正式报告。5-1 会优先采用 4-2/4-1 的最新真实产品状态，并追溯实际读取的报告版本。

## 输出

正式报告写入：

[Product Root]/06_SKILL分析报告/
5-1_[产品编号]_页面策略_Vx_YYYYMMDD_HHMMSS.html

报告包含页面核心战略、购买逻辑、卖点优先级、卖点—证据矩阵、购买顾虑、第一屏、信息架构、页面载体映射、品牌与视觉方向、表达风险，以及同源的 5-2/5-3 输入交接包。5-1 不直接写最终 Listing、不制作图片或视频；正式报告成功后自动调用 0-2 更新索引。
