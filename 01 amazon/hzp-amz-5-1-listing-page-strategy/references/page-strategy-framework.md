# 5-1 页面策略框架

## 输入优先级

页面表达采用以下优先级，并保留每条结论的来源：

最终真实产品状态（4-2/4-1） > 可靠实测和文件证据 > 消费者/市场证据 > 工程/供应商确认 > 人工页面判断 > AI推断。

这不是把人工输入降级为无效信息。人工明确的业务事实按事实记录；人工希望表达的卖点、视觉偏好和经验判断须保留原意并标注类别。

## 页面 P0/P1/P2 判断

- 页面 P0：消费者第一眼必须理解的购买理由，若遗漏会影响是否继续阅读。
- 页面 P1：强化 P0 的差异化或可信证据。
- 页面 P2：解除顾虑、补充场景/使用体验或强化品牌。

每个页面优先级都要回指产品机会 P0/P1、消费者问题、证据和购买顾虑。若卖点是市场常见配置，需有“明确更好 + 可感知价值 + 证据”才能升为 P1；否则保持辅助信息。

## Feature 到购买理由

每项不要只写材料、厚度、配件或外观。至少展开：

Feature → 消费者可感知价值 → 购买理由 → 证明方式 → 适合页面载体。

没有证明方式的项目不得强表达；没有消费者价值的项目不得占据页面 P0。

## 载体选择

- 标题：品牌、主关键词、产品身份和一个决定性差异化。
- 五点：购买结果、功能/结构、适配或使用、材料/质量和包装/支持（按产品实际情况取舍）。
- 主图：承担“为什么停下来”的销售任务，构图由 5-3 负责。
- 副图/视频：解释结构、场景、使用和证据。
- A+、Brand Story、Comparison Chart：补充理解、对比和信任，不替代核心首屏逻辑。

这是职责映射，不是最终文案或视觉成稿。

## 表达强度

只有真实测试、实测、正式规格、认证、专利检索或明确消费者证据支持时，才可使用相应强度。对“最安全、100%安全、永不损坏、认证、专利、第一”等表达必须记录依据；没有依据标记 [禁止表达] 或 [需合规/证据确认]。

## 冲突记录

当 03_产品页面思路与 4-1/4-2 或消费者证据冲突时，记录：人工观点、证据观点、冲突字段、新证据、影响、当前建议和需要谁确认。不得静默覆盖或把冲突双方混写成同一事实。
