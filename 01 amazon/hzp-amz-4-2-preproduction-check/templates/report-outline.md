# 4-2 正式 HTML 报告大纲

报告主体使用中文，所有状态带证据标签和来源。顶部显示：
- HZP Amazon 4-2｜量产前检查
- 产品：[产品代码] [产品中文名称]
- 最终样品/轮次
- 4-1 来源版本
- 一句话量产结论
- 最终量产决策
- BOM、规格、材料、成本、供应链、质量状态
- 最大量产风险
- 量产前必须完成事项
- 下一步动作

## 固定章节

1. 产品身份与《量产前检查结论》
2. 《输入版本追溯》
3. 《最终产品定义检查》
4. 《量产BOM检查》
5. 《关键规格冻结检查》
6. 《材料确认》
7. 《量产成本确认》
8. 《量产供应链检查》
9. 《质量标准与验货要求》
10. 《量产包装检查》
11. 《IP / 合规 / 安全检查》
12. 《量产风险清单》
13. 《量产前冻结清单》（A 已冻结、B 量产前必须完成、C 不得未经重新评审修改）
14. 《量产变更控制规则》
15. 《反方检查》
16. 《量产放行决策》
17. 数据与证据局限
18. 《名词术语解释》

每个检查域建议使用“状态卡 + 精确表格 + 证据/缺口说明”。没有证据时显示 [待验证] 或对应缺口标签，不用空白或经验数字。只有最终状态为通过或条件已满足时，才可在报告中显示进入量产。
