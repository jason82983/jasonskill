# 4-2 量产前检查框架

## 证据规则

- [FACT]：项目文件、实测、测试、工程/供应商/人工确认直接支持。
- [INFERENCE]：基于已确认事实的分析推断。
- [TO-VERIFY]：尚未取得足够证据。
- [DECISION]：HZP/QMT/工程/供应商已明确确认的决策。

供应商确认不等于量产稳定性验证；图片不等于材料确认；AI建议不等于规格；估算不等于报价。每个字段记录来源文件、日期、责任方和状态，不能用一条证据覆盖多个未确认字段。

## 状态矩阵

| 检查域 | 已确认的最低证据 | 缺失时展示 |
|---|---|---|
| 产品定义 | 4-1通过样品 + 当前量产版/人工或工程确认 | [产品定义待确认] |
| BOM | 正式BOM或工程/供应商确认 | [量产BOM待确认] |
| 规格 | 正式规格、实测或工程确认 | [关键规格待确认] |
| 材料 | 材料证明、正式BOM、测试或供应商确认 | [材料待确认] |
| 成本 | 有日期、数量、来源的真实报价 | [量产成本待确认] |
| 供应链 | 供应商、工艺、MOQ、交期等项目证据 | [供应链待确认] |
| 质量 | 质量标准、检验方法、缺陷定义 | [质量标准待建立] |
| 包装 | 包装结构/材料/标签/运输验证资料 | [包装待确认] |
| IP | 正式检索、律师或内部审核 | [IP风险待验证] |
| 合规 | 测试、认证、法规分析或正式确认 | [合规待确认] |
| 安全 | 针对产品风险的测试或工程确认 | [安全待验证] |

## 放行规则

- 通过：所有关键域可执行，重大风险已关闭。
- 有条件通过：只剩少量明确、低风险、可验证事项，且不改变核心产品定义。
- 暂缓量产：产品/样品本身无需重做，但 BOM、报价、质量、包装、供应链或合规等关键准备不完整。
- 退回4-1：量产版有需要真实样品重新验证的变化。
- 退回3-2：核心方案、核心消费者价值、核心结构/材料或成本边界需要重新开发。

## 变更回退

核心变化包括 P0/P1 逻辑、核心消费者价值、核心结构、核心材料、核心功能、安全设计和关键使用方式。核心变化退回 4-1；若变化表明方案本身不可行或要重做，退回 3-2。非核心的文件、包装文字或工艺小修正也必须记录责任方、完成标准和复核证据。

## 量产前冻结清单字段

每项记录：冻结/待完成/禁止变更类别、具体内容、证据、来源文件、确认人/责任方、日期、完成标准、风险和复核动作。AI不得仅凭“合理”把项目放进“已冻结”。
