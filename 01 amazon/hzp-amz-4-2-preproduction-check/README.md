# HZP Amazon 4-2｜量产前检查

## 30 秒运行

使用 4-2 Skill
产品：P001
Products Root：E:\【产品总目录】

4-2 读取当前产品最新有效的 4-1 打样评审，检查量产 BOM、规格、材料、成本、供应链、质量、包装、IP/合规/安全和放大风险，给出是否允许正式量产的结论。

## 什么时候使用

只有 4-1 已通过，或 4-1 的条件已全部完成时，才适合进行 4-2。4-2 不重新开发产品、不重新打样、不做最终验货。

## 输出

正式报告写入：
[Product Root]/06_SKILL分析报告/
4-2_[产品编号]_量产前检查_Vx_YYYYMMDD_HHMMSS.html

报告包含输入版本追溯、最终产品定义、BOM/规格/材料、成本与供应链、质量与包装、IP/合规/安全、量产风险、冻结清单、变更控制、反方检查和量产放行决策。正式报告成功后自动调用 0-2 更新报告索引；4-2 自己不生成 index.html。
