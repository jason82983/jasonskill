# HZP Amazon 3-1｜产品机会定义

## 30 秒运行

```text
使用 3-1 Skill
产品：P001
Products Root：E:\【产品总目录】
```

3-1 会读取当前产品的 `01_产品档案.md`、最新 2-1/2-2/2-3 报告，并优先读取 2-3 的《3-1输入交接包》，把市场机会和人工判断收敛成可验证的产品机会定义。

## 什么时候使用

当 2-2 已经给出市场进入决策，且你要明确“最值得抓住的产品机会是什么、为什么值得做”时使用。3-1 不重新做市场研究，也不直接设计材料、尺寸、BOM 或最终结构。

若 2-2 为 `NO-GO`，原则上停止；若为 `CONDITIONAL GO`，会把所有前置条件带入风险和验证清单，不会升级为 `GO`。

## 输出

报告保存到：

```text
[Product Root]/06_SKILL分析报告/
3-1_[产品编号]_产品机会定义_Vx_YYYYMMDD_HHMMSS.html
```

报告包含候选机会池、筛选与合并、正式产品机会定义、风险与关键验证项，以及交给后续 3-2 的《3-2输入交接包》。正式报告成功后自动调用 0-2 更新报告索引；3-1 自己不生成 `index.html`。


上游报告规则：如本次读取其他 Skill 正式报告，只在当前产品的 06_SKILL分析报告/ 中按产品编号、Skill 编号、最大 V 版本和同版本最大文件名时间戳选择最新有效正式版本；实际使用的文件会写入 HTML《输入版本追溯》。
