# 0-2 报告索引协议

## 固定入口

`[Product Root]/06_SKILL分析报告/index.html` 是当前产品所有正式 Skill 分析报告的唯一总入口。0-2 不在任何 Skill 子目录下创建第二个索引。

## 正式报告识别

标准文件名为：

`[技能编号]_[产品编号]_[技能中文名称]_V[版本号]_[YYYYMMDD]_[HHMMSS].html`

解析失败的旧报告仍可进入索引，显示文件名、所属 Skill 目录和打开链接，并标记 `历史报告`。文件系统中不存在的报告不得显示；`index.html`、测试、临时、demo 和 debug 文件不得进入索引。

## 排序

Skill 编号使用数字自然排序。同一 Skill 内按版本号降序；版本无法识别时按文件名时间戳，再按文件系统时间降序。分组第一份是当前最新报告，提供“打开最新报告”和轻量 `[最新]` 标签。

## 相对链接与离线

索引中的链接以 `06_SKILL分析报告/index.html` 为基准计算相对路径，禁止盘符、UNC 和 `file:///`。HTML 样式内嵌，移动或复制整个产品目录后仍可打开。

## 更新时机与失败

报告型 Skill 先成功生成并确认 Human Report 存在，再调用 0-2 重建索引。报告生成失败时不更新不存在的链接；索引失败不回滚或删除已生成报告，应分别报告报告状态和索引状态。0-2 生成索引后不再次调用自身，避免循环。

## 页面内容

顶部显示产品编号、产品名称、标题“分析报告中心”、正式报告总数、已产生报告的 Skill 数量和最近更新时间。报告行显示 Skill 编号、Skill 中文名称、产品编号、版本/历史标记、生成日期时间、文件名和打开链接。页面采用专业、克制、响应式卡片布局。
