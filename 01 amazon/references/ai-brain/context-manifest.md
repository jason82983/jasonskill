# Context Manifest

每个 AI Skill 应显式声明：

```text
GLOBAL: Operating System + Evidence Contract
DOMAIN: 本 Skill 所需 Domain Brain
UPSTREAM: 正式 Ground Truth 输入包
HISTORY: 是否读取历史决策
FORBIDDEN: 禁止重判、重抓或读取的内容
```

示例 606：

```text
GLOBAL: Operating System / Evidence Contract
DOMAIN: Search Intent / Benchmark Reality / Decision Challenge / Reason Trace
UPSTREAM: 602 Per-Benchmark High Precision Assets + 603 Intent Tree
HISTORY: 按 606 Contract 读取历史 Reality Evidence（如有）
FORBIDDEN: 重新判断 Precision、重建 Intent、重抓 Organic Rank、把 Occupancy 写成 Sales Market Share
```
