# Case Library

| Context | 容易犯的错误 | 正确推理方向 |
|---|---|---|
| 20 个低量排名词 vs 5 个核心大词 Top10 | 词多就等于占领强 | 分开看广度、需求覆盖和排名深度 |
| 两个 Benchmark 同词搜索量 20000 | 相加成 40000 | 市场容量只保留一份，Observation 可以多条 |
| 相关但宽泛的 baby proofing 词 | Relevance = High Precision | 检查完整购买意图与 Hard Conflict |
| Target 运行 14 天但只有 6 clicks | 14 天自动可决策 | 样本量和归因仍可能不足 |
| Bid 昨天刚改 | 用 Campaign 运行 30 天判断新 Bid | 从修改后的新 Evidence 重新计观察周期 |

案例只教推理方式，不覆盖当前产品事实、ASIN、搜索量或 Bid。
