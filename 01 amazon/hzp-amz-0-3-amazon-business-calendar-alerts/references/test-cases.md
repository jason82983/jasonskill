# V1验证场景（静态行为契约）

这些场景用于运行前后核对，不代表已经调用真实产品或 Amazon 数据。

| Case | 输入条件 | 预期行为 |
|---|---|---|
| A | 非季节产品、无异常 | `[今日无重大经营预警]` |
| B | Christmas 产品，开发截止还有10天 | P1 提醒开始开发 |
| C | 已超过开发截止 | `[明显滞后]`，同时给出经营方案选项 |
| D | 距 Season Start 60天，正常链路120天 | `[计划时间不足]` |
| E | 真实 Shipping=45天 | 使用45天，不使用默认30天 |
| F | Shipping未知 | 使用30天并标 `[系统默认规划参数]` |
| G | 真实 Cold Start=21天 | 使用21天，不使用默认30天 |
| H | Prime Day 当年未公布 | 不写猜测日期，标 `[日期待Amazon公布]` |
| I | Prime Day 官方已公布 | 写官方日期并标 `[官方日期]` |
| J | `0-3，P001` | 只生成 P001 产品预报 |
| K | `0-3` | 生成全局预报 |
| L | 广告异常 | 路由 6-3，不做完整广告诊断 |
| M | 库存风险 | 路由 7-1/7-2 |
| N | 昨日已提醒且今天阶段/风险无变化 | 不重复制造高优先级提醒 |
