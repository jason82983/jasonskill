# HZP Amazon 3-3｜产品方案评审

## 30 秒运行

```text
使用 3-3 Skill
产品：P001
Products Root：E:\【产品总目录】
```

3-3 会读取当前产品最新有效的 3-2 差异化产品方案，优先使用《3-3输入交接包》，评审它是否值得进入真实打样验证。

## 什么时候使用

当 3-2 已经形成推荐产品方案 V1，需要在投入样品成本前做正式方案评审时使用。3-3 不重新做市场研究、产品机会定义或完整产品设计，也不批准量产。

## 会检查什么

方案身份与完整性、机会—方案一致性、消费者价值、差异化真实性、工程/成本/供应链路径、风险分级和反方意见。最终只使用五种方案状态：通过进入打样、有条件通过、退回 3-2、停止该方案、证据不足暂不决策。

## 输出

正式报告写入：

```text
[Product Root]/06_SKILL分析报告/
3-3_[产品编号]_产品方案评审_Vx_YYYYMMDD_HHMMSS.html
```

只有通过或有条件通过时，报告才生成《4-1输入交接包》。正式 HTML 成功后自动调用 0-2 更新报告索引；3-3 自己不生成 `index.html`。

如果实际读取了上游正式报告，HTML 会包含《输入版本追溯》，记录实际使用的最新有效版本。缺失资料会标记待验证，不会被编造成已确认事实。
