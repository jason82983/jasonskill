# 阶段 3｜市场商业价值判断

> 状态：`【已正式设计】`。本文件只定义阶段 3，不重写阶段 1、阶段 2、阶段 4、阶段 5 和阶段 6；阶段 7 按独立的市场进入决策规则执行。

## 1. 核心问题与边界

阶段 3 回答：阶段 1 已确认的市场、阶段 2 已确认的真实需求，在商业上是否值得投入产品开发，以及本产品是否存在合理利润空间。

商业价值链为：市场有多少钱 → 钱主要在哪个价格带 → 钱被谁拿走 → 新品还能不能拿到钱 → 我们进入后有没有合理利润空间。

阶段 3 不提前判断竞争强度或进入难度，不把评论壁垒、品牌壁垒、广告竞争、CPC、点击集中度或头部垄断难度作为本阶段正式结论；这些留给阶段 4。点击份额和品牌点击份额不能替代销售额份额或销量份额。

## 2. 数据发现与字段语义

在同一次运行已锁定的 Product Root 内，围绕商业价值主动寻找：

- Opportunity Explorer 商品数据、主进入市场商品、头部/中腰部/新进入商品；
- 对标产品、竞争产品的真实销量/销售额、价格、上架日期、BSR 及历史数据；
- `01_产品档案.md`、产品成本、包装、头程、FBA、佣金、广告、退货损耗等已有可靠资料；
- 其他能支持商业价值判断的明确来源。

每项数据沿用全局规则：先定位源文件，读取实际字段，记录原始字段名、字段含义、时间窗口、统计对象和单位，再计算或下结论。文件名、BSR 或价格不能单独证明销量或销售额。缺失成本不得填入行业平均值。

## 3. 固定的五项分析

### 3.1 市场销售容量

优先汇总可靠、可验证的商品销量、销售额、月度/年度规模、头部/中腰部/新进入商品表现和有效销售商品数量。任何推算必须显示来源、输入、公式/方法，并标记 `[推算指标]`。

禁止仅根据 BSR 脑补月销量，或仅根据价格与 BSR 制造市场销售额。没有可靠销量/销售额依据时，显示 `[数据不足，无法可靠估算市场销售容量]`，但继续执行其他项目。

### 3.2 市场价格带

根据当前真实商品价格分布动态划分具有商业解释意义的区间，不固定套用示例价格带。每个价格带尽可能记录商品数量、代表商品、销量/销售额表现、市场销售贡献、对标产品和头部产品所在位置。

只有存在实际成交或销售证据时，才能称“主流成交价格带”或“高销量价格带”；商品数量多只能说明供给分布，不能替代成交证据。

### 3.3 销售价值分布

当有真实销售额/销量分布时，分析头部、中腰部和长尾的销售额/销量贡献，回答钱是广泛分布还是主要被少数商品拿走。该项是“销售价值集中”，必须与阶段 4 的“竞争集中”分开。没有真实销售分布时标记 `[销售价值分布证据不足]`，不得把点击份额伪装成销售额份额。

### 3.4 新品商业机会

主动读取数据源本身的新商品定义、上架日期、新品数量、新品销量/销售额、BSR、价格和增长。不得默认“上架 ≤180 天”就是 Amazon 官方定义；若需建立观察窗口，必须说明窗口并标记 `[分析口径]`。判断近期进入的新品是否真正获得商业结果。BSR只能作为辅助证据，没有可靠换算依据时不得生成具体销量。

### 3.5 本产品利润空间

读取当前项目已有的目标售价、产品成本、包装、头程、FBA 费用、Amazon 佣金、广告、退货损耗等真实成本。数据完整时，可计算毛利额、毛利率、贡献利润、盈亏平衡 ACoS 和售价敏感性；每一项注明输入和公式。缺失成本不得自行填入行业平均值，显示 `[数据不足]` 或 `[本产品利润空间待验证]`，并列出缺失字段。

## 4. 项目商业目标

只有当前 `01_产品档案.md` 或系统明确保存的本项目配置记录了目标利润、利润率、售价、销量或其他门槛，才能纳入比较。不得把一个产品目标套给其他产品，也不得仅凭记忆写入。未配置时标记 `[项目商业目标未配置]`。

## 5. 阶段结论

最终等级只允许：

- `【商业价值高】`
- `【商业价值中等】`
- `【商业价值有限】`
- `【商业价值不足】`
- `【证据不足】`

必须同时输出商业价值等级、一句话结论、3–5 条关键商业证据、最重要风险、数据局限和本产品利润空间状态。不能因为市场销售额大就直接判高，也不能只看利润率而忽略市场容量。

## 6. 图表与运行

正式 HTML 可使用市场销售容量 KPI、价格带分布、各价格带商业表现、销售价值分布、新品与老品表现、本产品售价利润情景等图表；没有真实数据时不生成对应图表，不制造销量、销售额、利润或时间序列。图表负责理解，表格负责查数，文字负责解释。

阶段 3 在阶段 1、阶段 2 后自动连续执行，不向用户逐阶段等待确认。普通数据缺失只影响对应项目并标记；只有产品身份冲突、市场身份无法确认或核心数据严重冲突且无法安全判断时才停止。阶段 4–7 按正式规则继续执行。
