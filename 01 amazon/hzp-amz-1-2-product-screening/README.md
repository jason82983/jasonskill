# HZP Amazon 1-2｜选品初筛

## 30 秒运行

```text
使用 1-2 Skill
候选：CAND-001（或 1-1 最新《1-2 输入交接包》）
Products Root：E:\【产品总目录】（如已建立）
```

1-2 用 1-1 的证据快速筛掉明显硬伤，判断哪些候选值得投入 2-1 深度分析。它不替代 2-1/2-2，也不输出最终 GO/NO-GO。

Skill 会自动继承 Candidate ID、1-1 来源、消费者需求、场景、反向证据和未知项，检查项目硬约束、需求、竞争进入、差异化、可感知性、商业空间、物流退货、供应链、团队、IP/合规、生命周期和失败成本，并优先做 Early Stop。缺数据会标记待验证，不会用经验数字填空。

候选已有 Product Root 时，正式报告写入 `06_SKILL分析报告/1-2_[产品编号]_选品初筛_V版本_日期_时间.html`，成功后调用 0-2 更新索引；纯候选阶段不伪造 Product Code，也不调用 0-2。
