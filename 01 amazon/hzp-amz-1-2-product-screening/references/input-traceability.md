# 上游输入版本追溯

1-2 读取 1-1 交接包和版本化正式报告时，先按产品身份和目标 Skill 限定范围，再选择最大 `V`。同一版本重复时，以文件名 `YYYYMMDD_HHMMSS` 最新者为准。不得依赖目录遍历顺序、文件修改时间或创建时间，也不得跨产品读取或静默回退。

报告输入记录至少包括：文件名、相对路径、来源 Skill、版本号、生成日期、读取日期、Product Code/Candidate ID 和证据状态。Candidate 尚无 Product Root 时只记录候选上下文，标记 `[候选阶段正式归档规则待确认]`，不伪造产品身份。

如果发现同一产品代码、同一 Skill 的文件名版本冲突，保留冲突说明并优先请求补充；不能自行选择不符合规则的文件。1-2 只消费 1-1 交接和必要原始证据，不重新生成上游报告。
