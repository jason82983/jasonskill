# 1-2 初筛检查清单

## 输入确认

- [ ] 最新有效的 1-1《1-2 输入交接包》已读取并记录版本/日期
- [ ] Candidate ID 稳定且未冒充 Product Code
- [ ] 产品身份、Marketplace、项目硬约束来源明确
- [ ] Product Root 存在时已读取 `01_产品档案.md`

## 证据检查

- [ ] 字段语义来自实际内容，不只相信文件名
- [ ] 每条关键结论有 `[原始市场数据]`、`[原始Review]`、`[1-1机会假设]` 或其他来源
- [ ] BSR、Suggested Bid、Click Share、Search Volume 未被错误转换
- [ ] 缺失数据标为证据不足，未用经验数字填空

## 决策检查

- [ ] Early Stop 由事实、证据和逻辑支持
- [ ] 低竞争与低需求已区分
- [ ] 高销量与品牌壁垒已分开检查
- [ ] 新品成功原因、差异化、消费者可感知性和页面表达性已检查
- [ ] 商业空间未在无真实成本时计算正式净利润
- [ ] 大件、退货、售后、供应链和团队匹配未被自动化简化
- [ ] IP/合规未发现不等于无风险
- [ ] 生命周期和机会窗口已对比执行周期
- [ ] 反向证据和最大未知项已列出

## 交接检查

- [ ] 《关键验证清单》使用 `【必须验证】`、`【重要验证】`、`【补充验证】`
- [ ] 2-1 输入交接包只包含三种进入状态
- [ ] 未使用 GO / CONDITIONAL GO / NO-GO
- [ ] Product Root 正式报告成功后才调用 0-2
- [ ] Candidate 纯扫描阶段未伪造 Product Code 或调用 0-2
