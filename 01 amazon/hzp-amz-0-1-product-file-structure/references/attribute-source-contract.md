# Current Product Attribute Source

标准路径：`05_分析源数据/01_产品数据/本产品/产品属性信息.txt`

身份：`CURRENT_PRODUCT_ATTRIBUTE_SOURCE`

职责：保存已经由用户、供应商/工厂、规格书、包装资料、实物或其他可靠来源确认的当前产品客观属性事实。它不是 Listing 文案、营销表达、市场/竞品资料、Skill 报告或 AI 推测。

与 `产品识别 - 文本文案.txt` 的边界：后者回答“这个产品是什么”，承载识别文本、描述、功能和使用语义；本文件回答“有哪些已经确认的客观属性”，承载材质、尺寸、重量、颜色、规格、数量、配件、结构、安装、兼容性、电源和其他事实。

初始模板：

```text
【产品属性信息】

产品编码：
产品名称：

【基础属性】

【尺寸/规格】

【材质】

【数量/套装】

【结构/配件】

【安装/使用】

【兼容性】

【其他已确认属性】

【数据备注】
```

初始化规则：`Missing → Create`，`Existing → Preserve`。CREATE 自动创建；CHECK 只报告缺失；ORGANIZE/MIGRATE 只有在明确补齐结构时才补建。任何模式都不得覆盖、清空、改写已有内容，也不得把无法确认的属性填成事实。
