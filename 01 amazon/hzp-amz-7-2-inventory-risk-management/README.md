# HZP Amazon 7-2｜库存风险管理

## 30 秒运行

```text
使用 7-2 Skill
产品：P001
Products Root：E:\【产品总目录】
```

7-2 持续检查库存、销量、在途、Lead Time、补货执行、库龄、资金占用和推广联动，判断 7-1 预测是否仍成立，并把真实风险路由到 7-1、6 阶段、页面、供应链或产品阶段。

运行前准备：

- `[Product Root]/01_产品档案.md`
- 最新有效的 7-1 报告（优先《7-2输入交接包》）
- `[Product Root]/05_分析源数据/` 的库存、销售、采购和物流资料
- `[Product Root]/07_产品资料/` 的供应商、库龄、成本、促销和运营记录

Skill 会区分 Available、Reserved、Inbound、在途、SKU 和真正可售时间，比较 7-1 原预测与当前现实，输出断货、积压、老化、在途、偏差和资金风险，以及是否需要重算 7-1。缺少真实数据时会标记【关键库存数据不足｜暂无法可靠判断】，不会编造库存、到货、成本或风险。

正式报告写入：

`[Product Root]/06_SKILL分析报告/7-2_[产品编号]_库存风险管理_Vx_YYYYMMDD_HHMMSS.html`

报告成功后自动调用 0-2 更新当前产品索引；7-2 不自行维护 `index.html`。
